# HORASAN — To‑Do App

A small React + TypeScript to‑do list that uses localStorage to persist tasks.

Getting started

1. cd todo-app
2. npm install
3. npm run dev

The app runs on http://localhost:5173 by default.

What it includes

- Add, complete, delete tasks
- Filter (All / Active / Completed)
- Clear completed and reset all
- Persisted in localStorage under the key `horasan_todos_v1`

Notes

- This is a minimal example to integrate into the existing HORASAN repository. You can move the files into your main frontend as needed.
